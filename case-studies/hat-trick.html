HAT-TRICK

One API behind a football social network where players, coaches, clubs, agents and scouts each see a different product.

01 — The problem

Football recruitment runs on contacts. A player with talent but no agent rarely reaches a scout, and clubs have no single place to find and follow players. HAT-TRICK set out to be that place: a social network built around football careers.

The hard part for the backend: five very different user types sharing one platform, each with their own profile data, permissions and actions, on both web and mobile.

02 — Architecture

A single Laravel API serves the website and the mobile apps. Every request goes through the same authentication and role checks, so the web and mobile clients can't drift apart.

03 — Key decisions

  • One account table, role-specific profiles. Shared fields live on the user; each role (player, coach, club, agent, scout) gets its own profile table.
  • Permissions in one place. Role checks sit in policies and middleware, not scattered through controllers, so adding a new action means one rule, not five.
  • Feeds built for mobile. Paginated endpoints with eager-loaded relations to keep the number of queries flat as the feed grows.

04 — Result

The platform is live on web and mobile, with all five account types running on the same API.
